# Deep Streaming View Clustering（ICML 2025）

This repo contains the code and data of our paper "Deep Streaming View Clustering". If you have any questions about the source code, please contact: hl_yuan0822@163.com.

## Requirements

pytorch==1.2.0 

numpy>=1.19.1

scikit-learn>=0.23.2

munkres>=1.1.4

## Datasets

You can find these datasets used in the paper at [Quark](https://pan.quark.cn/s/8d8c394501f7).

## Training

Run the code by
```bash
python main.py 
```
